# Sample token set

These tokens are test vectors, not production data. They are generated by
`make_tokens.py` in this folder and written to `tokens.txt`.

## The signing secret is public

The HMAC signatures are genuine, computed with `hmac` and `hashlib` over the
real signing input. The shared secret is a published test secret:

```
your-256-bit-secret
```

This string appears in widely circulated JWT tutorials and the RFC 7515 style
examples. It is safe to commit precisely because it is public knowledge. Do not
use it for anything real. Because the secret is published, `tokenscope verify`
can confirm the four HMAC tokens against it, which demonstrates that the
signatures are real rather than placeholder bytes.

## Determinism

All timestamps are fixed relative to `NOW = 1767225600`, which is
2026-01-01T00:00:00Z and matches `tokenscope.cli.DEFAULT_NOW`. Regenerating the
file produces byte-identical output, and auditing it produces byte-identical
findings, because the auditor never reads the wall clock.
